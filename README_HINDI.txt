RHK FF TOURNAMENT - ANDROID PROJECT

Is project mein:
- App name: RHK FF Tournament
- Launcher icon: RHK FF red/black
- Existing tournament web app Android WebView ke andar
- JavaScript aur local storage enabled

APK banane ka phone-friendly tareeqa:
1. GitHub par sign in karo aur New repository banao (naam: RHK-FF-Tournament).
2. Is ZIP ke andar ki saari files repository ke main folder mein upload karo.
3. Repository mein Actions tab kholo.
4. 'Build RHK FF APK' workflow select karo.
5. 'Run workflow' dabao.
6. Build complete hone par workflow run kholo, Artifacts mein RHK-FF-Tournament-APK download karo.
7. ZIP artifact extract karke app-debug.apk install karo.

Note:
- Ye debug APK hai, testing/install ke liye.
- Public Play Store launch ke liye signed release build, privacy policy, testing aur Play Console requirements alag se poori karni hongi.
- App abhi local-device demo hai: registrations aur profile sirf isi phone par save hote hain. Online multiplayer/admin sync, secure login, real payments aur server/database abhi nahi hain.
- App ke andar entry fee/prize fields demo labels hain; koi payment processing nahi hoti.
